# Contributing to @allauth/browser

Thank you for your interest in contributing to `@allauth/browser`!

## Code of Conduct

By participating in this project, you are expected to uphold our code of conduct.

## How to Contribute

1. **Fork the repository** on GitHub.
2. **Clone your fork** to your local machine.
3. **Create a new branch** for your feature or bug fix: `git checkout -b feature/your-feature-name`.
4. **Make your changes**.
5. **Run tests** to ensure everything is working correctly: `npm test`.
6. **Lint your code**: `npm run lint`.
7. **Commit your changes** following [Conventional Commits](https://www.conventionalcommits.org/).
8. **Push to your fork** and submit a pull request.

## Development Setup

```bash
npm install
npm run build
```

## Pull Request Guidelines

- Ensure your code follows the existing style and conventions.
- Include unit tests for any new features or bug fixes.
- Keep pull requests focused on a single issue or feature.
